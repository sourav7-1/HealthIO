# Phases 0 and 1: architecture, rules and backend foundation

## What was built
- **Monorepo:** pnpm workspaces + Turborepo (`apps/web`, `packages/*`) and a uv project for `apps/api`. Pre-commit hooks: ruff, mypy, eslint/tsc, gitleaks.
- **Docs:** rules (now `PROJECT_RULES.md`), ADR 0001 (stack), API conventions, threat model v0, DPDP register v0.
- **API core (`apps/api/app/core`):**
  - `config.py`: typed settings, `HIO_` environment prefix
  - `logging.py`: structlog with PHI/PII redaction by key name and by identifier pattern (phone, email, ABHA, Aadhaar-like numbers, bearer tokens)
  - `errors.py`: RFC 9457 problem+json for every error; rejected input is never echoed
  - `middleware.py`: request ID, access log (route template only, no query strings), security headers, `no-store`
  - `policies.py`: policy marker, with `public` for now; a test fails when a route has no policy
  - `rate_limit.py`: Redis fixed-window limiter used as a route dependency
  - `db.py`, `cache.py`, `storage.py`: async SQLAlchemy engine, Redis, S3 presigned POST/GET with SSE and a size cap
- **Endpoints:** `GET /health` (liveness) and `GET /ready` (database, Redis and storage checks, 503 when degraded).
- **Workers:** Celery app (acks-late, JSON only) with a heartbeat task on beat.
- **Web:** Next.js 16 skeleton with a route group per portal and the typed API client wired in (replaced by a Vite SPA in Phase 1b, see ADR 0002).
- **Contracts:** `pnpm api:client` exports OpenAPI and regenerates `packages/api-client/src/schema.d.ts`. CI fails if it is out of date.
- **CI:** API (format, lint, mypy, pytest with coverage), API integration against compose services, contract drift, web (lint, typecheck, test, build), gitleaks.

## Demo
```bash
docker compose -f docker-compose.dev.yml up -d --build
curl -i http://localhost:8000/ready
# 200 {"status":"ok","checks":{"database":"ok","redis":"ok","storage":"ok"}}
curl http://localhost:8000/api/v1/nope          # problem+json 404 with request_id
docker compose -f docker-compose.dev.yml stop redis && curl -i http://localhost:8000/ready   # 503 degraded
docker compose -f docker-compose.dev.yml start redis
docker compose -f docker-compose.dev.yml logs worker | grep heartbeat   # beat → worker every 60 s

cd apps/api && HIO_INTEGRATION=1 uv run pytest -m integration   # presigned S3 round trip, DB, Redis
```

## Environment notes
- The host Postgres port is **5433**, to avoid clashing with a locally installed PostgreSQL on 5432.
- MinIO images come from `quay.io/minio/*`; the Docker Hub images are no longer published. Dev MinIO has a static KMS key, so SSE-S3 (`AES256`) behaves as it does on AWS.
- TypeScript is pinned to 5.9 (see ADR 0001).
